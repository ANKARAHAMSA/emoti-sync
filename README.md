## ✨ Overview

**EmotiSync** is a state-of-the-art, privacy-first computer vision web platform that performs real-time facial emotion recognition, multi-face landmark telemetry, continuous mood tracking, dynamic ambient UI color synchronization, and mood-adaptive Web Audio soundscapes.

Built with pure client-side AI processing, zero camera streams ever leave your local device.

---

## 🚀 Key Features

- 🎥 **Optical Stream Feed**: High-FPS live webcam emotion detection with 68-point facial mesh wireframes and glowing neon bounding boxes.
- 🌈 **Dynamic Ambient Aura**: The application's backdrop aura and glass tint fluidly transition in real-time to match your primary emotion:
  - ☀️ **Happy**: Warm Solar Gold
  - 🌊 **Neutral**: Electric Cyan
  - ⚡ **Surprised**: Radiant Purple
  - 🌧️ **Sad**: Deep Sapphire Blue
  - 🔥 **Angry**: Vivid Crimson
  - 🛡️ **Fearful**: Neon Orange
  - 🌿 **Disgusted**: Emerald Green
- 📊 **Session Telemetry & Analytics**: Continuous tracking of 7 primary emotions, computing **Positivity Index**, **Emotional Stability**, and **Peak Dominant State**.
- 🎵 **Mood Audio Soundscapes**: Web Audio API synthesizer producing procedural ambient soundscapes aligned with your detected emotional state.
- 🖼️ **Offline Media Scanner**: Drag-and-drop scanner for multi-face photo and video analysis with face crop extraction.
- 📸 **Snapshot & Log Export**: Capture annotated frame snapshots with telemetry overlays or export full session logs in CSV and JSON formats.

## 🛠️ Tech Stack

- **Core**: HTML5, ES Modules, Canvas 2D API
- **Styling**: Modern Vanilla CSS Glassmorphism (`backdrop-filter: blur(20px)`), Google Outfit & Inter Typography
- **Analytics & Icons**: Chart.js 4, Lucide Icons, Canvas Confetti
- **Build Tool**: Vite 6, Vitest
- **Deployment**: Vercel
